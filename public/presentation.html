  • نماذج الذكاء الاصطناعي العامة تعطي إجابات غير دقيقة (Hallucinations).
  • تجاهل التاريخ المرضي وعمر المريض عند تقديم النصيحة.
  • عدم ربط الإجابات بمصادر طبية موثوقة.
✅ الحل مع Shaheeq AI

مساعد طبي ذكي يعتمد على RAG و Onboarding

  • جمع بيانات المريض (العمر، الحالة الصحية) في بداية المحادثة.
  • ربط الاستفسارات بقاعدة معرفية طبية موثوقة حصراً.
  • عرض المصادر الطبية مع كل إجابة لتعزيز الموثوقية.

التطبيق العملي والمكتبات البرمجية 💻

🎨 Frontend & UI
  • Next.js 15 (App Router): لبناء واجهة سريعة ودعم الـ SSR.
  • Tailwind CSS v4: بناء التنسيقات الحديثة والتجاوب الكامل.
  • Framer Motion & Lucide React: أنيميشن تفاعلي للـ Onboarding وأيقونات ملونة.
⚡ Backend & AI Stack
  • Next.js API Routes: معالجة الطلبات محلياً مع حماية المفاتيح (API Keys).
  • Google Generative AI / OpenAI SDK: التواصل المباشر مع النماذج اللغوية.
  • MongoDB & Mongoose: تخزين بيانات المستخدمين، الجلسات، وسجل الشات.
🔍 RAG Pipeline & Vectors
  • Embedding Models: تحويل المستندات الطبية إلى متجهات عدادية (Vectors).
  • Vector Database (e.g. Pinecone / MongoDB Atlas Search): تخزين الـ Chunks للبحث السريع.
  • Similarity Search (Cosine Distance): مطابقة سؤال المريض بالـ Chunks الأكثر صلة.

تفاصيل معمارية الـ RAG والـ Chunking ✂️

📐 استراتيجية الـ Chunking (Chunking Parameters)

يتم تقطيع كتب ومقالات طب الأمراض التنفسية باستخدام طريقة RecursiveCharacterTextSplitter:

  • Chunk Size: 500 - 800 Tokens (لتجنب تشتيت النموذج).
  • Chunk Overlap: 100 - 150 Tokens (15-20% تداخل لعدم انقطاع سياق الجمل الطبية).

⚙️ خطوات دمج الـ Context بالـ Prompt

  1. سحب الـ Chunks المناسبة وتنسيقها.
  2. إرفاق بيانات الـ Onboarding (العمر + المرض المزمن).
  3. صياغة الـ System Prompt لإجبار النموذج بالرد حصراً من الـ Context وإظهار المصدر (Sources).

س: ازاي بتتأكدوا إن الـ RAG مش هيرجع معلومات ملهاش علاقة؟

ج: عن طريق تحديد درجات التشابه (Similarity Threshold) واستخدام تقنيات Embeddings دقيقة ومخصصة للنصوص الطبية.

س: كيف تؤثر بيانات الـ Onboarding على إجابة المساعد؟

ج: بيتم إرفاق عمر المريض وحالته المرضية داخل الـ System Prompt لإلزام الموديل بتقديم استشارة مناسبة لحالته وفئته العمرية.
